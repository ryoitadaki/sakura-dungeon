# 少女サクラと不思議のダンジョン v0.124.0

## このフォルダについて

v0.124.0 の GitHub 登録用一式です。ゲーム本体 `index.html` と外部BGMを同じリポジトリ内で管理します。

## ファイル構成

```text
index.html
README.md
audio_assets_manifest.json
assets/
  audio/
    sakura-theme.mp3 / .ogg
    novis-forest.mp3 / .ogg
    mysterious-dungeon.mp3 / .ogg
    underwater-sewer.mp3 / .ogg
    misty-valley.mp3 / .ogg
```

**重要:** `assets/audio/` のフォルダ名・階層・音源ファイル名を変えないでください。`index.html` はこの相対パスからMP3/OGGを読み込みます。HTML単体だけではBGMは再生されません。

## GitHubへの登録

ZIPを展開し、中身をリポジトリのルートに配置してください。GitHubのWeb画面ではフォルダ自体をファイルとして登録するのではなく、`assets/audio/` の中にある10個の音源ファイルをそのフォルダ内にアップロードします。GitHub Desktopなら展開したフォルダ構造を保持したままコピー・コミットできます。

GitHub Pagesで公開する場合は、リポジトリの Settings → Pages で公開ブランチとルートフォルダを選択します。

## 今後のBGM追加

既存ダンジョンの曲を差し替えるときは、同じファイル名のMP3/OGGを `assets/audio/` に配置して差し替えます。新しいダンジョン用の曲を追加する場合は、MP3/OGGをこのフォルダに追加したうえで、ゲーム側のダンジョンIDとBGM URLマップにも登録する必要があります。新曲をHTML内へBase64埋め込みしないでください。

## v0.124.0の変更

1. 水晶の描画を共通化し、濃霧の渓谷でも地下水道と同じ緑色クリスタルを表示。水晶があるタイルだけに描画します。
2. 自然発生判定間隔を生存中の同行仲間数に応じて動的に変更。
   - 0匹: 15ターン
   - 1匹: 13ターン
   - 2匹: 12ターン
   - 3匹: 11ターン
   - 4匹: 10ターン

仲間数の変更時に経過ターンをリセットしません。壺内・倉庫内・死亡中の仲間はカウントしません。既存の自然発生率、出現候補、ウェイト、上限は変更していません。

セーブ形式 `SAVE_FORMAT_VERSION` は `1` を維持しています。
